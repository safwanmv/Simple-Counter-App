# Simple React Counter App

This is a beginner-friendly React application that demonstrates the use of components, hooks (`useState`), and props. It features a counter with increment, decrement, and reset functionality.

## 🚀 Features

- React functional components
- `useState` hook for state management
- Reusable `CounterButton` component
- Clean and responsive button styling
- CSS hover effects with transitions

## 🧱 Project Structure

```

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/safwanmv/react-counter-app.git
cd react-counter-app
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm start
```

## 📦 Build for production

```bash
npm run build
```

## 🛠 Technologies Used

- React
- CSS

## 📌 Example

A basic counter app with buttons to:
- Increase the counter
- Decrease the counter
- Reset the counter to 0
